Amethyst for 1.26.x is a mixed source library, the core runtime is fully open source, however amethyst is a largely bring your own types library past 1.21

## Why close source parts of amethyst:
- Largely amethyst has gone pretty unused by the general developer community meaning the extra work im doing to keep this project open source doesn't particularly feel that worth it, especially when going closed source would allow me a lot more freedom and speed.

- Reverse engineering MC is not really applicable to 99% of people in the minecraft space, if amethyst were to continue being something usable by others, I think the best thing for that would be to make our own scripting layer in JS for client-side modding. To be clear though this is not on the near term roadmap of amethyst, but I have considered it.

- 1.21.x code will remain fully open source & for people interested in trying out modding, 1.21.x is really the best version to mod, 1.26.x is pretty unapproachable to beginners, which is partially why I'm going to stop trying to cater to this target group.
